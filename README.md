# 개미 키우기 v1.0.0 — 정식 출시

GitHub Pages에서 실행하는 모바일 중심 브라우저 게임입니다. `index.html`, `style.css`, `balance.js`, `game.js` 네 파일을 동일 폴더에 올리면 됩니다.

## 주요 콘텐츠

- LV.20 육성, LV.10 첫 진화 3종 및 LV.20 두 번째 진화 6종
- 원정 6지역, 자원 3종, 제작 장식 6종, 희귀 발견물 6종, 원정대 3인 편성
- 왕국 시설 3종 최대 LV.5, 완료 개미 일꾼 배치, 주간 목표 3종
- 자동 육성 3모드, 진행 횟수 10/25/50/100회, 속도 3단계
- LV.10 전에는 원정권이 증가하지 않으며 LV.10 달성 행동부터 완료 행동 6회마다 1장 적립됩니다.

## v1.0 안정화

- 육성 행동·선택형 이벤트 저장 실패 시 경험치·자원·원정권·진화를 이전 상태로 복구
- 저장 실패 시 자동 육성 중지
- 설정 → 저장 상태 점검: 저장 형식과 임시 쓰기 검증 (서버 전송 없음)
- 데이터 초기화 전 별도 브라우저 복구 슬롯에 백업 및 검증
- 탭 간 변경 시 진행 중 선택 이벤트 복원, 키보드 접근성·모션 감소 지원
- JSON 백업·복원과 과거 v0.1~0.9 저장 데이터 호환

## 데이터 보존

- 기존 키: `little-ant-game-mvp-v1` 및 `schemaVersion: 1` 유지
- v1.0 전 상태는 `little-ant-game-before-v1.0`에 1회 저장
- 초기화 전 상태는 `little-ant-game-before-reset-v1.0`에 저장
- 서버 계정/클라우드 동기화 없음. 브라우저 사이트 데이터 삭제 전 JSON 파일로 백업하세요.
- 익명 플레이 통계는 비활성화되어 있습니다.

## 배포 전 검증

`node --check game.js` 와 브라우저 통합/회귀 테스트를 확인한 뒤 `main`에 배포하세요.
