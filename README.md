# 개미 키우기 v1.0.1 — 자동 육성 및 전직 외형 개선

v1.0.0의 기능과 저장 구조를 유지한 호환 패치입니다.

## 업데이트 내용

- 자동 육성 중 선택형 돌발 이벤트를 만나면 선택 완료 후 남은 횟수를 자동 재개합니다.
- LV.10 첫 진화 결과 확인 후에도 정상 상태라면 자동 육성을 재개합니다.
- 위험 상태(안전 중지 설정 활성화), 저장 실패, 화면 이동/숨김, 새로고침, LV.20 최종 진화에서는 자동 재개하지 않습니다.
- LV.10 첫 진화 3종에 개별 복장, LV.20 두 번째 진화 6종에 개별 장비/외형을 추가했습니다.
- 현재 육성 중인 개미, 진화 결과 팝업, 과거 완료 기록의 외형이 같은 규칙을 사용합니다.
