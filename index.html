v0.2 상태 대응 회복을 유지합니다. LV.10 첫 진화와 LV.20 두 번째 진화도 유지됩니다. LV.10 전에는 원정권을 획득할 수 없으며, LV.10 이후 완료 행동 6회마다 원정권을 획득합니다. 완료 개미 최대 3마리를 원정대로 편성할 수 있습니다. 당근도 소량의 EXP를 제공합니다. 자동 육성은 실행 횟수와 속도를 선택하고, 이벤트·진화 때 확인 후 수동 재개할 수 있습니다.

업데이트 소식

업데이트 후 첫 접속에는 최신 소식을 안내합니다. 이전 업데이트 기록도 버전별로 확인할 수 있습니다.

익명 플레이 통계

게임 운영 개선을 위해 페이지 방문, 첫 육성 행동, 진화, 이벤트 선택, 도전과제 달성 여부를 통계로 수집할 수 있습니다. 이름이나 입력 내용은 전송하지 않습니다. 동의하지 않아도 게임을 이용할 수 있습니다.

관리자 측정 ID가 등록되지 않아 현재 통계를 수집하지 않습니다.

Google Analytics로 통계가 전송됩니다. 언제든 동의를 철회할 수 있습니다. 동의를 철회하면 통계 수집을 중단합니다.

저장 정보

게임은 브라우저의 저장 공간에 자동 저장됩니다. 기기나 브라우저를 변경하면 기록이 자동 이동하지 않습니다.

자동 저장 사용 중

업데이트 이전 저장 상태는 최초 전환 시 브라우저에 별도 백업됩니다. 현재 게임 데이터를 JSON 파일로 내보내거나, 이전에 내보낸 파일에서 복원할 수 있습니다. 복원은 기존 데이터를 대체하며, 먼저 별도 백업을 만듭니다.

최대 5MB JSON 파일 · 기존 게임 데이터와 병합하지 않습니다.

정식 출시 이용 안내

어떤 순서로 플레이하나요?

당근과 채찍으로 LV.10 첫 진화를 달성하고, LV.20 두 번째 진화를 완성하세요. 완료 개미는 왕국 시설에 배치하거나 원정대에 편성할 수 있습니다.

원정권은 언제부터 받을 수 있나요?

LV.1~9 동안에는 원정권이 적립되지 않습니다. LV.10 달성 행동부터 완료된 육성 행동 6회마다 원정권 1장이 적립되며, 최대 5장을 보유할 수 있습니다.

저장 데이터는 어디에 보관되나요?

현재 브라우저의 저장 공간에만 보관됩니다. 기기를 변경하거나 브라우저의 사이트 데이터를 삭제하면 사라질 수 있습니다. 설정에서 JSON 백업을 내려받은 뒤 새 기기에서 가져오세요.

자동 육성은 앱을 닫아도 계속되나요?

아닙니다. 화면을 떠나거나 이벤트를 선택할 때 자동으로 멈추며, 필요하면 사용자 확인 후 수동으로 재개합니다.

데이터 초기화

초기화하기 전 현재 저장 데이터를 브라우저에 별도 보관합니다. 초기화 후 기록은 자동으로 되돌아오지 않으므로 중요한 데이터는 JSON 파일로 백업해 주세요.
