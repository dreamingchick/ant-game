# v1.1 구현 및 QA 보고서

**판정: 기능 구현·저장 호환성 검사 통과, 성장 속도 균형 QA 미통과. 정식 배포 보류.**

## 구현 범위

LV.10 첫 진화 3종을 유지하고 LV.20 두 번째 진화 6종을 체크포인트로 전환했습니다. LV.30에서 세 번째 진화 12종으로 육성을 완료합니다. EXP 요구량은 `50 + 10 × (level − 1)`, LV.10 이후 채찍 기초 EXP 14, 당근 고정 EXP 3을 유지합니다. LV.50·총 5회 진화는 장기 목표이며 이번에 해금하지 않습니다.

2차 분기는 LV.10~20의 행동, 3차 분기는 LV.20~30의 행동만 사용합니다. 모두 채찍 비율 `<55%` A / `≥55%` B이며 정확히 55%는 B입니다. LV.20을 달성한 행동은 2차 카운터에만 포함됩니다. 이벤트 대응 선택은 행동 횟수를 추가하지 않습니다.

| 계보 | 패시브 | 구현 |
|---|---|---|

수치 변화량은 기본 행동과 2차 보정을 먼저 합산한 뒤 0~100으로 제한합니다. 상태 대응 회복과 1차 태평 회복을 이후 적용합니다. 경험치는 행동 직전 상태로 효율을 판정합니다. 취소 이벤트는 최종 EXP를 0으로 만듭니다. 1·2차 육성 효과는 LV.30까지 중첩되며, 육성 완료 후 당근·채찍은 종료됩니다.

활성 5종 / 미활성 7종. 현재 정밀 기계공과 대지의 선구자는 같은 보상 범위를 갖습니다. 실제 제작 재료 목록에서 자동 판별하므로 새 자원을 임의로 만들어 분류하지 않습니다. 위험·손실·대기 시스템의 가상 수치나 무의미한 가짜 타이머를 추가하지 않습니다. 따라서 12종 모두가 현재 수치 혜택을 갖는다는 의미의 균형 승인은 불가능합니다.

원정은 완료 기록에서 **패시브 대표 개미 한 마리**를 별도로 선택합니다. 기존 최대 3마리 원정대의 기본/지역 특화 보너스는 그대로이며, 3차 수치 효과는 대표 한 마리만 적용합니다. 현재 LV.30 개미도 완료 기록에 즉시 등록되어 참여할 수 있습니다. 기록관의 상세 정보는 실제 저장된 내역만 표시하고 옛 저장 파일에 없던 상세 값은 `과거 기록 없음`으로 표시합니다.

보상형은 패시브 적용 전 실제 지급 예정 보상(기본·무작위·시설·일꾼·원정대 보너스 포함)에 5%를 적용합니다. `유형:자원`별로 정수 백분의 일 단위를 누적해 100마다 1개를 지급합니다. 같은 유형으로 대표 개미를 바꾸어도 소수 몫을 유지합니다. 인벤토리 한도 999,999를 넘는 정수 보상은 기존 상한 규칙에 따라 지급하지 않으며, 잔여 소수만 보존합니다. 지급량·원정권·소수 몫·주간 목표는 같은 저장 트랜잭션으로 확정되어 저장 실패 시 함께 되돌립니다.

모든 3차 진화에는 독립 SVG 의상, 전용 수집 칭호, 계보 도감, LV.30 진화 애니메이션, 당근·채찍·이벤트 요약, 전용 기념 깃발 장식을 제공합니다. 감소된 모션 설정을 존중합니다. 완성 후 기존 원정권과 시설·원정대·꾸미기 활동을 이용합니다. 육성 완료 이후 새 원정권을 무한 생성하는 기능은 추가하지 않았습니다.

## 저장 호환성

저장 키 `little-ant-game-mvp-v1`과 `schemaVersion:1` 유지. 신규 필드는 선택적으로 복원합니다. 구버전 LV.10·20 완료 기록을 자동으로 재육성시키지 않습니다. 현재 LV.20 완료 개미에만 `기록을 보존하고 LV.30까지 계속 키우기`를 제공합니다. 보관 중인 다른 개미를 임의로 다시 꺼내 키우는 기능은 추가하지 않았습니다.

이어 키우는 동안 기존 완료 기록과 ID·시설 배치·원정대 참조는 유지합니다. 성장 누적 통계에서 해당 개미를 두 번 합산하지 않습니다. LV.30 완료 시 같은 기록 ID를 갱신하고 원본 LV.20 기록을 `legacyLevel20` 스냅샷으로 보관합니다. 새 LV.30 완료 개미는 새 기록을 생성합니다. 내보내기/가져오기는 LV.30·3차 계보·추가 장식·패시브 소수 누적값·대표 개미를 검증합니다.

## 성장 속도 시뮬레이션

각 2차 유형 6종 × 채찍 비율 40%/50%/60% × 고정 시드 100회 = **1,800회**. 실제 `playAction`·이벤트·선택 대응·효율·경험치·진화 함수를 사용하고, 반복 실험 동안 화면·저장 I/O·음향만 생략했습니다. LV.20 시작 능력치는 모두 의욕 60/스트레스 20/나태함 10, EXP 0으로 통일합니다. 10행동마다 비율이 정확한 행동 블록을 섞고, 이벤트 난수와 행동 난수는 분리합니다. 이벤트 대응은 항상 첫 선택지를 사용합니다. 각 조건은 기존 1차 패시브도 포함하므로 이번 2차 보정만의 순수 효과 측정은 아닙니다. 실제 LV.20 도달 상태나 자동육성 전략 전체를 대표하지 않습니다.

## 배포 전 남은 판정

1. 2차 성장 속도 격차 10% 목표의 적용 범위를 유지하며, 기존 1차 특성과 2차 보정의 기여도를 분리한 후 수치를 재검토해야 합니다. 현재 수치의 정식 배포 승인은 보류합니다.
2. 미활성 7종은 기존 콘텐츠가 없다는 명확한 제한입니다. 정식 버전에서 전체 계보의 동등한 실효성을 요구한다면 별도 기획 변경이 필요합니다.
3. 대표 선택·추가 장식·LV.20 이어 키우기 및 LV.30 달성 장면의 Android 실제 기기 검수가 필요합니다.

CI 성공은 기능 회귀 검사의 성공입니다. 위 균형 QA 미통과 상태를 해제하거나 정식 배포를 승인하는 신호로 사용하지 않습니다.
