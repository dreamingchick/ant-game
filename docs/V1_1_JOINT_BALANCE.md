# v1.1 1·2차 공동 밸런스 확정안

2026-11-06 · 사용자 승인 범위: 1차 패시브 수치까지 함께 조정. **9,300회 실제 엔진 검증에서 자동 성장 격차 기준 통과.**

태평의 회복, 천재의 긍정 이벤트 증폭, 근면의 채찍 EXP라는 역할은 유지합니다. EXP 요구 공식·기본 행동·상태 상하한·효율 계수·이벤트 확률·45%/55% 진화 경계는 바꾸지 않았습니다. 기존 3차 진화 12종과 실제 연동 5종/미활성 7종 정책도 유지합니다.

## 채택 수치

| 1차 계보 | 이전 | 채택 |
|---|---|---|
| 태평 · 여유로운 마음 | 당근 스트레스 추가 회복 −5 | **−1** |
| 천재 · 기발한 발상 | 긍정 이벤트 유익 효과 +20% | **+50%** |
| 근면 · 성실한 훈련 | 채찍 EXP +15% | **+5%** |

| 2차 | 이전 | 채택 |
|---|---|---|
| 꽃정원 · 향긋한 휴식 | 당근 의욕 +2 | **당근마다 의욕 +2** |
| 초원 개척 · 야생 적응 | 당근 나태함 증가량 −2 | **당근 2회마다 증가량 −1** |
| 별빛 학자 · 심화 통찰 | 긍정 증폭 +10%p, 총 +30% | **+30%p, 천재와 총 +80%** |
| 태엽 발명 · 정교한 반복 | 채찍 나태함 −2 추가 | **채찍 2회마다 −1 추가** |
| 공방 장인 · 장인의 집중 | 모든 채찍 기초 EXP +5% | **채찍 2회마다 기초 EXP +5%** |
| 강철 수호 · 강인한 정신 | 채찍 스트레스 증가량 −2 | **채찍 2회마다 증가량 −1** |

### 계산과 발동 간격

1차 효과는 LV.10 이후 각 행동에 적용합니다. 2차 효과는 LV.20 이후 적용하며, 2회 간격은 해당 행동의 **두 번째·네 번째·여섯 번째… 사용**에 발동합니다. 당근 행동은 채찍 간격에, 채찍 행동은 당근 간격에 영향을 주지 않습니다. 다음 발동까지 남은 횟수를 현재 패시브 설명에 표시합니다.

공방 장인은 발동한 채찍에서만 `round(14×1.05)=15 → 행동 직전 효율 반올림 → 근면 1.05 반올림 → 이벤트 보정` 순서입니다. 비발동 채찍은 기본 14를 사용합니다. 효율 100%, 이벤트 없음일 때 각각 16 EXP/15 EXP입니다. 명목 +5%를 모든 상황의 최종 EXP +5%라고 표현하지 않습니다. 보너스가 없는 순서에서도 근면의 1차 효과는 적용합니다.

별빛 학자는 천재의 1.5에 0.3을 더해 유익 효과를 1.8배로 만듭니다. 긍정 이벤트의 의욕 +5는 +9, 스트레스 −5는 −9가 됩니다. 긍정 이벤트에 섞인 불리한 효과와 부정 이벤트는 증폭하지 않으며 발생 확률도 유지합니다. 상태 상·하한은 그대로입니다.

주기화는 14 EXP에 +5%를 반올림하면 명목치보다 큰 1 EXP 증가가 되고, 작은 상태 보정도 장기적으로 이벤트 노출까지 바꾸는 문제를 완화합니다. 계보별로 임의의 공통 경험치 보정이나 숨겨진 보상 배율을 추가하지 않았습니다.

## 성장 격차 결과

동일 행동 전략 내 `(최대 행동 수 중앙값 / 최소 중앙값 − 1)×100`으로 비교합니다. 소수점 반올림 전 값으로 10% 이하를 판정합니다.

| LV.20~30 · 채찍 비율 | 조정 전 | 조정 후 |
|---|---:|---:|
| 40% | 27.22% | **6.92%** |
| 50% | 47.70% | **7.18%** |
| 60% | 34.91% | **6.79%** |

| 추가 조건 | 채찍 40% | 채찍 50% | 채찍 60% |
|---|---:|---:|---:|
| LV.20~30 별도 시드 | 7.54% | 7.60% | 7.54% |
| LV.20~30 상태 대응 선택 | 6.02% | 7.73% | 6.75% |
| LV.20~30 불리한 시작 상태 | 6.85% | 6.50% | 6.75% |
| LV.10~20 세 부모 비교 | 4.98% | 4.35% | 3.72% |
| LV.10~20 별도 시드 | 4.80% | 4.56% | 4.59% |

모든 위 조건이 10% 이하입니다. 자연 성장 검증은 LV.1부터 진화를 강제하지 않고 행동하며, 각 전략 100회·총 300회 완료했습니다.

| 채찍 | 자연 성장 계보 | 총 행동 수 중앙값 |
|---|---|---:|
| 40% | 태평 → 꽃정원 → 생명의 정원사 | 908.5 |
| 50% | 천재 → 별빛 학자 → 은하의 기록관 | 861 |
| 60% | 근면 → 강철 수호 → 왕실 근위대장 | 821.5 |

자연 성장 세 전략 사이의 속도를 동일하게 만드는 것을 목표로 삼지는 않습니다. 같은 행동 전략 안의 계보 격차 기준과 구분합니다. 자연 성장은 위 3개 대표 계보를 확인하며, 12종 전부의 LV.30 경계·완료·저장·외형은 별도 기능 검사로 검증합니다.

### 방법과 한계

- 기본 6종×3전략×100시드 1,800회, 별도 시드/상태 대응/불리한 시작 상태 5,400회, LV.10~20 세 부모×3전략×두 시드 구간 1,800회, 자연 성장 300회 = **9,300회**.
- 기본 시작 상태는 의욕60/스트레스20/나태함10. 불리한 시작 상태는 40/60/60입니다. 행동은 10회 블록에서 40%/50%/60% 비율을 유지하며 블록 순서를 섞습니다. 별도 시드는 +10000을 사용합니다.
- 상태 대응 선택은 현재 효율과 위험/주의 벌점으로 평가하며, 모든 이용자의 최적 전략이라는 뜻은 아닙니다. 이외에는 이벤트 첫 선택지를 사용합니다.
- 채택안 검증은 실제 엔진에 확정된 설정 그대로 실행합니다. 설정 덮어쓰기나 빠른 탐색용 꾸미기 생략을 사용하지 않습니다. 표본에 없는 모든 상태·행동 전략의 균형을 보장하지 않습니다.
- 탐색 결과는 [v1.1-joint-candidates.json](v1.1-joint-candidates.json), 기본 결과는 [v1.1-balance-results.json](v1.1-balance-results.json), 확장 검증은 [v1.1-joint-validation.json](v1.1-joint-validation.json)에 있습니다.
- 이전 확정안과 조정 전 진단은 [V1_1_BALANCE_DIAGNOSIS.md](V1_1_BALANCE_DIAGNOSIS.md)에 보존합니다.

## 저장 및 회귀 검증

별도의 저장 스키마를 추가하지 않습니다. `stage3Counters.carrot/whip`로 주기를 계산하므로 기존 LV.20 완료 기록의 선택 재개, 진행 중 LV.20~29 저장 파일, 내보내기/가져오기에 호환됩니다. 재접속해도 발동 순서를 유지합니다. 구버전에서 이미 처리되어 저장된 EXP·상태는 소급 재계산하지 않습니다.

저장 실패 시 EXP·상태·발동 진행도 모두 되돌리고, 재시도에서 보너스를 한 번만 적용합니다. 선택 이벤트로 잠시 멈춘 행동은 기본 효과가 이미 저장된 상태로 복구하고, 선택 완료 시 주기 효과를 다시 적용하지 않습니다. 기록 ID·기존 도감·원정대·시설 배치는 유지합니다.

기능 검증: 기존 회귀 66개, v1.1 기능/주기/저장/진화 검사 140개, 행동·표정 9개, PWA 13개, 배포 증거 검사 16개로 **244개 통과**. 정적 계약·JavaScript 문법 검사도 통과했습니다.

## 배포 기준

Pages 배포는 `verify`와 `balance-qa` 모두 성공해야 진행합니다. `balance-qa`는 기본 1,800회뿐 아니라 확장 7,500회의 보고서를 요구하며 게임 버전과 소스 SHA-256, 각 조건의 표본·누락·중복을 검사하고 격차를 재계산합니다. LV.10~20 또는 별도 시드에서 10%를 넘으면 배포를 차단합니다. 자연 성장 300회가 예상 계보로 완주하지 못한 경우도 차단합니다.

이 보고서의 자동 기준 통과는 Android 실제 기기의 입력·설치·재접속 검수를 대신하지 않습니다. 정식 서비스 반영은 이 PR의 병합/배포 절차에서 진행하며 이번 공동 수치 조정으로 자동 병합하지 않습니다.
